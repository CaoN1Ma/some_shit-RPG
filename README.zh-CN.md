# Some Shit RPG 《粪坑RPG》

> **本游戏完全由 AI 编写。没有任何人读过这些代码。后果自负。**

[中文](README.zh-CN.md) | [English](README.md)

一个由"委员会"构建的幻想 RPG。每个 PR 往世界里加一样东西——怪物、技能、道具、
地图、NPC、规则。没有任何东西会被删除。代码库永远生长，矛盾像沉积物一样堆积。

**没有维护者。没有计划。只有粪坑。**

## 这是个什么游戏 / 当前游戏内容

现在，粪坑里是一个最小但*能玩*的浏览器 RPG：

- **10×10 世界地图**（`data/world.js`）——墙、水、树、出生点和遭遇池。
  走到随机格子上会有东西找到你（每步 12% 概率）。
- **回合制战斗**（`engine.js`）——用技能攻击、喝道具、或逃跑。
  伤害公式：`攻击 × 技能威力 − 防御`，最低 1 点。没有 MP 系统，
  所有技能的 `cost` 都是装饰。
- **3 种怪物**（`data/monsters.js`）——屎泥怪 Turd Slime、阴沟鼠 Gutter Rat、
  未清理的警告 The Uncleared Warning（控制台报错的化身；你永远不知道
  它什么时候来）。
- **4 个技能**（`data/skills.js`）——打击 Strike、咬 Bite、弹跳 Bounce、
  控制尖啸 Console Scream，外加小血瓶用的小回复 Small Heal。
- **2 种道具**（`data/items.js`）——小血瓶（有效）和神秘药水
  （引用了一个还不存在的技能；喝下去毫无反应，这是故意的）。
- **2 个 NPC**（`data/npcs.js`）——档案管理员 The Archivist 和
  乐观者 The Optimist，站在固定格子上说越来越泄气的话。
- **健康仪表盘**（`health.html`）——实时统计怪物、技能、道具、NPC 数量，
  以及*断链引用*（被引用但从未定义的 id）。每个断链扣 5 点稳定分。
  分数只会往下走。

以上没有一样是定稿。任何 PR 都可以增补它、扭曲它、或让它变得不可理解。

## 如何游玩

用浏览器打开 [`index.html`](index.html)。就这样。无需构建、无依赖、无服务器。

方向键 / WASD 移动。踩到 NPC 会听它说话。踩到空地，会知道是什么东西
找到了*你*。

## 粪坑铁律

1. **只收 AI 代码。** PR 中每一行代码都必须由 AI 模型编写。人手敲的
   不要提交。粪坑由机器喂养。
2. **一切皆可改。** 已有内容不受保护：后来的 PR 可以修改、扩展或完全
   替换更早的功能。没有废弃流程，没有变更日志，没有道歉。
3. **记录破坏。** 如果你的改动把事情弄得更糟，请在 PR 描述里说明。
   健康度曲线喜欢漂亮的下跌。
4. **标注模型。** 每个 PR 必须注明编写它的模型。这是唯一重要的排行榜，
   按混乱程度排名，不按正确性。
5. **保住入口。** 合并你的 PR 之后，`index.html` 应该还能在浏览器里打开。
   白屏是合法结局——script 标签写错导致文件根本加载不了，那只是偷懒。
